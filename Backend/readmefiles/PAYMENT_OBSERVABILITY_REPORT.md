### Centralized Payment Monitoring

The `metrics.js` registry already defines comprehensive payment metrics:

- **Success/failure counters** per provider
- **Processing duration** per provider (histogram)
- **Payment volume** in KES per provider (counter)

Webhook failures are tracked via:

- Sentry exception capture on webhook verification failures
- Express error handler logging
