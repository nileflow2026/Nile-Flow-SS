## Implementation

The `Release Intelligence Service` (`Backend/src/observability/releaseIntelligence.js`) tracks every deployment with full metadata:

### Metadata Captured Per Release

| Field            | Source                          | Example                      |
| ---------------- | ------------------------------- | ---------------------------- |
| `sha`            | Git commit SHA                  | `abc1234`                    |
| `branch`         | Git branch                      | `main`, `staging`, `develop` |
| `buildNumber`    | EAS build number or CI run ID   | `123`                        |
| `runtimeVersion` | Expo fingerprint or app version | `fp_abc...`                  |
| `otaUpdateId`    | EAS Update group ID             | `uuid-v4`                    |
| `channel`        | EAS channel                     | `production`, `staging`      |
| `deployedBy`     | GitHub actor                    | `engineer@nileflow.com`      |
| `timestamp`      | ISO 8601                        | `2026-06-09T20:00:00Z`       |

### Service API

```javascript
const {
  recordRelease,
  getReleaseHistory,
  getLatestProductionRelease,
} = require("./src/observability/releaseIntelligence");

// Record a new release
recordRelease({
  sha: process.env.APP_VERSION || execSync("git rev-parse --short HEAD"),
  branch: process.env.BRANCH || "unknown",
  buildNumber: process.env.BUILD_NUMBER || "unknown",
  runtimeVersion: process.env.RUNTIME_VERSION || "unknown",
  otaUpdateId: process.env.OTA_UPDATE_ID || null,
  channel: process.env.CHANNEL || "development",
  deployedBy: process.env.DEPLOYED_BY || "ci",
});

// Get latest 50 releases
const history = getReleaseHistory();

// Get current production release
const prod = getLatestProductionRelease();
```
