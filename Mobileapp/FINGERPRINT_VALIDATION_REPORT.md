## Impact

- **Before:** `EAS_SKIP_AUTO_FINGERPRINT=1` disabled automatic fingerprint
  computation during EAS Build, causing EAS Update to infer runtime version
  from app version alone.
- **After:** Fingerprint is computed automatically by EAS Build and embedded
  into native binaries. EAS Update matches updates to exact native build.
- **Risk:** Minimal. Fingerprint is backward-compatible; existing devices
  continue receiving updates until their native binary changes.
